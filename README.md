# A 股情绪看板

每日自动更新的 A 股市场情绪仪表盘。把「今天市场几度」变成一个 0~100 的数字，
并给出该阶段对应的操作纪律。

> 口径与《情绪周期与龙头实战》（教程第 17 册）完全一致。
> **本页为个人学习工具，不构成任何投资建议。历史统计不预测未来。**

---

## 情绪值怎么算

```
情绪值 = 50% × 涨停家数分位
       + 30% × 连板家数分位
       + 20% × (100 − 炸板率分位)
```

- 「分位」= 今天的数值在**过去 60 个交易日**中的百分位排名（0~100）
- **只用历史数据，不含未来函数**——每天收盘后就能算出来
- 用分位而不是绝对家数，是为了让不同年份可比：牛市里 100 家涨停可能只是常态，熊市里 40 家就是火热

## 六个阶段

| 阶段 | 判定 | 该做什么 |
|---|---|---|
| ① 冰点 | 情绪值 < 25 | 只低吸或空仓，**不碰打板** |
| ② 启动 | < 40 且 5 日均线向上 | 小仓位试错，只做最强的 |
| ③ 发酵 | 55~75 且 5 日均线向上 | **短线唯一可以主动进攻的窗口** |
| ④ 高潮 | ≥ 75 且仍在上升 | 只减不加 |
| ⑤ 退潮 | < 40 且 5 日均线向下 | 停手，不接飞刀 |
| ⑥ 二次冰点 | 回到 < 25 且跌停家数收敛 | 等右侧信号（连板高度重建） |

> ⚠️ **关键区分：「买指数」与「打板」是两件事。**
> 冰点之后 20 个交易日等权指数平均 **+1.95%**，但同期打板的中位数是 **−6.65%**。
> 「情绪冷」对买指数是机会、对打板是陷阱，六个阶段无一例外。

## 数据来源与口径

| 项目 | 说明 |
|---|---|
| 日常行情 | 新浪财经行情接口（全市场日线快照，约 5,200 只） |
| 缺失补齐 | 新浪日线接口（补中间交易日，见 `backfill.py`） |
| 种子历史 | 本机通达信前复权日线（仅首次初始化用） |
| 涨停判定 | 主板 9.6% ／ 创业板与科创板 19.6% ／ ST 4.8% ／ 北交所 29.6% |
| 连板判定 | 今日涨停 且 上一交易日也在涨停名单中 |
| 炸板率 | 当日最高价触及涨停价、但收盘未涨停的家数 ÷ 触及家数 |
| 涨跌家数 | 按收盘涨跌幅正负计数（不含停牌、无成交） |

## 使用

```bash
# 首次：生成种子历史 + 全市场代码表（需要本机有通达信日线缓存）
python build_dashboard.py --init

# 每日：拉最新行情 -> 算情绪 -> 重绘 index.html
python build_dashboard.py

# 只重绘页面（不联网）
python build_dashboard.py --offline

# 补齐中间缺失的交易日（例如几天没跑，连板数会断层）
python backfill.py
```

产物：

```
index.html            看板主页（单文件，数据内嵌，可直接托管）
data/sentiment.json   每日指标历史（含最近 90 天的涨停名单）
data/codes.json       全市场代码表
```

## 每日自动更新

已在 WorkBuddy 配置定时任务：**每个交易日 16:00**（收盘后）自动执行
「拉行情 → 更新看板 → 推送本仓库」，并在会话里汇报当日情绪值与阶段。

## 目录

```
build_dashboard.py   主脚本：抓取 / 计算 / 生成页面
backfill.py          补齐缺失交易日（多线程，约 4 分钟跑完全市场）
data/                数据文件
index.html           生成的看板
```

## 已知局限

- 涨停阈值用板块限幅**近似**，与交易所口径可能有个别差异；ST 股按 4.8% 判定
- 新浪日线**不复权**，除权日的下跌可能被误记为跌停（影响跌停家数，占比很小）
- 分位窗口固定 60 个交易日；初始化不足 60 天时情绪值显示「数据不足」
- 情绪值是**对当日市场状态的描述**，不构成对次日的预测
- 本工具不含任何个股推荐，也不提供买卖信号
