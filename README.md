# A 股情绪看板

每日自动更新的 A 股市场情绪仪表盘。把「今天市场几度」变成一个 0~100 的数字，
并给出该阶段对应的操作纪律；同时给出**波段闸门（今天该不该开新仓）**与**候选清单**。

> 情绪口径与《情绪周期与龙头实战》（教程第 17 册）一致；
> 波段选股口径与《波段战法》（第 19 册）、《选股与建仓路线图》（第 20 册）一致。
> **本页为个人学习工具，不构成任何投资建议。历史统计不预测未来。**

---

## 情绪值怎么算

```
情绪值 = 50% × 涨停家数分位
       + 30% × 连板家数分位
       + 20% × (100 − 炸板率分位)
```

- 「分位」= 今天的数值在**过去 60 个交易日**中的百分位排名（0~100）
- **只用历史数据，不含未来函数**——每天收盘后就能算出来
- 用分位而不是绝对家数，是为了让不同年份可比：牛市里 100 家涨停可能只是常态，熊市里 40 家就是火热

## 六个阶段

| 阶段 | 判定 | 该做什么 |
|---|---|---|
| ① 冰点 | 情绪值 < 25 | 只低吸或空仓，**不碰打板** |
| ② 启动 | < 40 且 5 日均线向上 | 小仓位试错，只做最强的 |
| ③ 发酵 | 55~75 且 5 日均线向上 | **短线唯一可以主动进攻的窗口** |
| ④ 高潮 | ≥ 75 且仍在上升 | 只减不加 |
| ⑤ 退潮 | < 40 且 5 日均线向下 | 停手，不接飞刀 |
| ⑥ 二次冰点 | 回到 < 25 且跌停家数收敛 | 等右侧信号（连板高度重建） |

> ⚠️ **关键区分：「买指数」与「打板」是两件事。**
> 冰点之后 20 个交易日等权指数平均 **+1.95%**，但同期打板的中位数是 **−6.65%**。
> 「情绪冷」对买指数是机会、对打板是陷阱，六个阶段无一例外。

## 波段闸门与候选（第 19／20 册口径）

首页第二块。核心是回答一个问题：**今天该不该开新仓？**

**闸门判据**：等权全市场指数近 20 个交易日的涨跌幅

| 大盘环境 | 判据 | 闸门 | 波段超额 | 胜率 |
|---|---|---|---|---|
| 上涨 | 20 日 > +3% | 开放 | +0.20% | 29.4% |
| **震荡** | **±3% 以内** | **关闭** | **−0.21%** | **21.6%** |
| 下跌 | 20 日 < −3% | 开放 | −0.11% | 29.5% |

> 866 个交易日实测：闸门开放 **63.0%**、关闭 **37.0%**；平均每年可做 136 天、空仓 80 天；
> 最长一次连续关闭 **25 个交易日**。所以「空仓等待」是常态，不是意外。

**八级硬条件漏斗**（不是打分，任何一级不过就出局）：

```
① MA20 > MA60 且 MA60 上行       ⑤ 高于 MA60 ≤ 25%
② 近 5 日内曾收盘跌破 MA20        ⑥ MA20÷MA60−1 在 2%~5%
③ 今日收盘 > MA5 且收涨           ⑦ 20 日日均成交额 ≥ 5,000 万
④ 收盘 ≥ MA20 × 1.02             ⑧ 剔除 ST 与停牌
```

实跑示例（2026-09-30）：**5,184 → 2,158 → 1,501 → 543 → 103 → 97 → 41 → 32**（0.6%）。
其中主板 26 只（3 万元账户可执行）、需权限 5 只（创业板/科创板/北交所）、剔除 ST 1 只。

**候选清单字段**：收盘、高于 MA60、发散度、MA20 缓冲、20 日均额、评分；
初始止损 ＝ 收盘 × 0.90（移动止损），加仓参考位 ＝ MA20。

> ⚠️ **候选 ≠ 推荐 ≠ 买入信号。** 这个入场信号的超额收益只有 **+0.01%**（≈ 市场平均水平），
> 选股器的作用是**排除不该做的票**，不是保证赚钱。开盘前仍需核对第 19 册第 8 章的十项清单。

## 阶段 1 · 空跑记录（自动化）

`swing_screen.py` 每次运行都会把当日结果追加到 `data/stage1_log.json`
（**同一交易日覆盖，幂等**），首页显示「已完成 X/20 个交易日 + 闸门开放 Y 天」与记录表。

这就是《选股与建仓路线图》阶段 1 要求的「连续 20 个交易日记录」——
现在它是全自动的：**每个交易日 16:00 跑完，记录就自动多一行**。

## 数据来源与口径

| 项目 | 说明 |
|---|---|
| 日常行情 | 新浪财经行情接口（全市场日线快照，约 5,200 只） |
| 缺失补齐 | 新浪日线接口（补中间交易日，见 `backfill.py`） |
| 波段选股行情 | 东财前复权日线（90 根）→ 腾讯 → 新浪，三级兜底 |
| 种子历史 | 本机通达信前复权日线（仅首次初始化用） |
| 涨停判定 | 主板 9.6% ／ 创业板与科创板 19.6% ／ ST 4.8% ／ 北交所 29.6% |
| 连板判定 | 今日涨停 且 上一交易日也在涨停名单中 |
| 炸板率 | 当日最高价触及涨停价、但收盘未涨停的家数 ÷ 触及家数 |
| 涨跌家数 | 按收盘涨跌幅正负计数（不含停牌、无成交） |

## 使用

```bash
# 首次：生成种子历史 + 全市场代码表（需要本机有通达信日线缓存）
python build_dashboard.py --init

# 每日：拉最新行情 -> 算情绪 -> 跑波段选股 -> 重绘 index.html
python build_dashboard.py

# 只重绘页面（不联网、不跑选股）
python build_dashboard.py --offline

# 单独跑波段选股（东财 → 腾讯 → 新浪 三级兜底，约 60~120 秒）
python swing_screen.py
python swing_screen.py --offline      # 只用缓存

# 补齐中间缺失的交易日（例如几天没跑，连板数会断层）
python backfill.py
```

产物：

```
index.html                看板主页（单文件，数据内嵌，可直接托管）
data/sentiment.json       每日情绪指标历史（含最近 90 天的涨停名单）
data/codes.json           全市场代码表
data/swing.json           当日波段闸门 + 候选 + 阶段 1 进度
data/stage1_log.json      阶段 1 逐日记录（每日追加，同交易日覆盖）
```

> 行情缓存（约 23 MB）写在**系统临时目录**，不进项目目录——否则会被打进部署包。

## 每日自动更新

已在 WorkBuddy 配置定时任务：**每个交易日 16:00**（收盘后）自动执行
「拉行情 → 更新情绪 → 跑波段选股 → 重绘看板 → 推 GitHub → 重新发布线上 → 汇报」。

## 目录

```
build_dashboard.py   主脚本：抓取 / 计算 / 生成页面（含 do_swing 调用）

```

## 已知局限

- 涨停阈值用板块限幅**近似**，与交易所口径可能有个别差异；ST 股按 4.8% 判定
- 新浪日线**不复权**，除权日的下跌可能被误记为跌停（影响跌停家数，占比很小）
- 分位窗口固定 60 个交易日；初始化不足 60 天时情绪值显示「数据不足」
- 情绪值是**对当日市场状态的描述**，不构成对次日的预测
- **行情源在高并发下会被限流**：`swing_screen.py` 用 6 线程 + 三级兜底；
  若出现「完成 0 只」，不要重跑（会继续打接口），改用 `--offline` 走缓存
- 波段候选是**形态筛选结果**，入场信号的超额仅 +0.01%，**不是买入信号**
- 本工具不含任何个股推荐
